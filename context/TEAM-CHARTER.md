## 🎨 استانداردهای فنی

### رنگ‌ها
- اصلی: `#39FF14` (سبز فسفری)
- پس‌زمینه: `#0a0a0a`
- کارت: `bg-neutral-900/60`
- متن اصلی: `text-white`
- متن ثانویه: `text-gray-400`

### فناوری‌ها
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Supabase (PostgreSQL)

### قواعد کد
- TypeScript کامل
- RTL برای همه صفحات
- فارسی برای UI
- کامپوننت‌ها زیر ۲۰۰ خط

### ساختار پوشه‌هاapp/ → صفحات
components/ → کامپوننت‌های مشترک
data/ → داده‌های ثابت
lib/ → کتابخانه‌ها
context/ → مستندات تیم
public/ → فایل‌های عمومی
