# 🚗 ماشین من (My Car)

اپلیکیشن جامع خدمات خودرو برای بازار ایران. هدف این پروژه، ساخت یک پلتفرم یکپارچه است که تمام نیازهای یک راننده، تعمیرکار، فروشنده قطعات و امدادگر را در یک جا پوشش می‌دهد.

---

## 📖 درباره پروژه

**ماشین من** در حال حاضر در فاز MVP (حداقل محصول قابل ارائه) قرار دارد. تمرکز اولیه روی سه بخش است:

1. **فروشگاه قطعات** — خرید آنلاین قطعات یدکی با ضمانت
2. **پروفایل کاربری** — تفکیک کاربران به چهار دسته
3. **زیرساخت چهارسطحی خودرو** — برند → مدل → تیپ → سال

پروژه توسط **مهدی**، مکانیک حرفه‌ای با ۲۳ سال تجربه در صنعت خودرو، ساخته می‌شود. هدف، حل مشکلات واقعی صنعت با استفاده از فناوری مدرن است.

---

## 🛠️ تکنولوژی‌ها (Tech Stack)

- **فریمورک:** Next.js 16 (App Router)
- **زبان:** TypeScript
- **استایل:** Tailwind CSS v4
- **فونت:** فعلاً فونت پیش‌فرض سیستم (برنامه‌ریزی برای Vazirmatn)
- **آیکون‌ها:** SVG داخلی + ایموجی
- **مدیریت حالت:** React useState (فعلاً)
- **ذخیره‌سازی موقت:** localStorage (شبیه‌سازی لاگین)
- **دیتابیس:** هنوز اضافه نشده (برنامه‌ریزی برای Supabase)
